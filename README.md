Student Marks Report System

📌 Project Overview

The Student Marks Report System is a simple C++ program that analyzes students' marks and generates a performance report. It calculates total marks, average marks, highest and lowest marks, and the number of passed and failed students.

✨ Features

- Accepts student count between 1 and 100
- Reads and stores student marks using arrays
- Calculates total marks
- Calculates average marks
- Finds highest marks
- Finds lowest marks
- Counts passed and failed students
- Uses functions for different operations
- Uses arrays and loops
- Allows repeated analysis
- Uses 40 as the pass mark

🛠️ Technologies Used

- C++
- Arrays
- Loops
- Functions
- Conditional Statements

🚀 How to Compile and Run

Step 1: Compile

g++ student_marks_report.cpp -o student_marks_report

Step 2: Execute

Linux / macOS:

./student_marks_report

Windows:

student_marks_report.exe

📊 Program Operations

The program accepts student marks and performs the following calculations:

- Total marks
- Average marks
- Maximum marks
- Minimum marks
- Passed students
- Failed students

⚠️ Limitations

- Supports a maximum of 100 students.
- Uses a fixed-size array.
- Marks are entered manually.
- Does not permanently save student reports.

🎯 Purpose

This project demonstrates fundamental C++ programming concepts through a practical student marks analysis application.
